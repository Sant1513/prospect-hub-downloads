Install Prospect Hub

Capture the people on a LinkedIn search page with one click, and keep one shared, de-duplicated list for the team. Setup takes about 5 minutes.

1. Download

Version 0.2.7 · Windows, Mac, Linux · no account needed

Download Prospect Hub setup (.zip)

Before you start

You need Google Chrome and Node.js 24 or newer. Check Node by running node -v in a terminal. If it's missing, install the "LTS" version from nodejs.org. The Windows setup opens that page for you if needed.

2. Run setup

Recommended: paste one command. This works even when Smart App Control blocks downloaded files, and you don't need to download the zip yourself.

  1. Open PowerShell: press Start, type PowerShell, then press Enter.
  2. Click Copy command below, paste it into PowerShell (right-click pastes), and press Enter.
    PowerShell
    $ErrorActionPreference = 'Stop'
if (-not (Get-Command node -ErrorAction SilentlyContinue)) { Start-Process 'https://nodejs.org/en/download'; throw 'Install Node.js (LTS), then paste this again.' }
if ([int](node -p "process.versions.node.split('.')[0]") -lt 24) { Start-Process 'https://nodejs.org/en/download'; throw 'Node.js 24 or newer is needed. Install it, then paste this again.' }
$zip = "$env:TEMP\prospect-hub-setup.zip"; $tmp = "$env:TEMP\prospect-hub-setup"; $app = "$env:LOCALAPPDATA\ProspectHub"
Invoke-WebRequest 'https://github.com/Sant1513/prospect-hub-downloads/releases/latest/download/prospect-hub-setup.zip' -OutFile $zip -UseBasicParsing
Expand-Archive $zip $tmp -Force
Get-ChildItem $tmp -Recurse | Unblock-File
if (Test-Path "$app\helper-app\install-service.mjs") { node "$app\helper-app\install-service.mjs" --remove }
New-Item -ItemType Directory -Force "$app\helper-app", "$app\extension" | Out-Null
Copy-Item "$tmp\Prospect Hub setup\helper\*" "$app\helper-app" -Recurse -Force
Copy-Item "$tmp\Prospect Hub setup\extension\*" "$app\extension" -Recurse -Force
node "$app\helper-app\install-service.mjs"
Start-Sleep 3; Start-Process 'http://127.0.0.1:47615/'; explorer "$app\extension"
Write-Host "Done. In Chrome: chrome://extensions > Developer mode ON > Load unpacked > $app\extension" -ForegroundColor Green
  3. The command installs the helper, which keeps your data on this computer and syncs it to the team. It then opens the helper page and the extension folder for the next step. To update later, paste the same command again; your data is kept.
If the helper page doesn't open (helper not running)

Smart App Control can also block the start-at-sign-in entry. Start the helper by hand with this command, and keep that PowerShell window open while you use the extension:

PowerShell
node "$env:LOCALAPPDATA\ProspectHub\helper-app\helper.mjs"
Alternative: setup.cmd (when Smart App Control is off)

Download the zip with the button above. Right-click it, choose Extract All…, then double-click setup.cmd in the extracted folder. If Windows shows "Windows protected your PC", click More info → Run anyway.

  1. Unzip the download, open a terminal in that folder, and run bash setup.sh
  2. Setup installs the helper as a background service and opens the helper page and the extension folder.

3. Add the extension to Chrome

  1. Open chrome://extensions (Chrome blocks links to it, so paste it into the address bar).
  2. Turn on Developer mode (switch at the top right).
  3. Click Load unpacked and choose this folder:
    Windows: %LOCALAPPDATA%\ProspectHub\extension
    Mac: ~/Library/Application Support/ProspectHub/extension
  4. Click the puzzle icon in the toolbar, pin Prospect Hub, then click it to open the side panel.

4. Connect to your team

  1. In the side panel, enter the pairing code shown at http://127.0.0.1:47615/. That page only works on your own computer once setup has run.
  2. Ask your admin for a one-time enrollment code.
  3. Side panel → Settings → Enroll. Master URL: https://abhishesh.tail66d6e3.ts.net:8443 . Then enter the code.

5. Use it

  1. On LinkedIn or Sales Navigator, run a people search with any filters. On Sales Navigator, scroll to the bottom of the results once so all 25 leads load.
  2. Side panel → Collect → LinkedIn page → Capture people on this page.
  3. Check the list (new people are pre-selected, and people the team already has are marked), then click Save.
  4. Go to the next results page on LinkedIn and capture again.

LinkedIn's terms restrict tools that copy data from its pages, and LinkedIn may limit accounts that use them. Prospect Hub reads only what is on your screen, and only when you click. It never scrolls, changes pages or opens profiles for you.

Updating to a new version

When the side panel says Update available: on Windows, paste the same PowerShell command again; on Mac/Linux, download the zip and run setup again. Then click the reload icon on Prospect Hub in chrome://extensions. Your saved data is kept.

Uninstalling

Remove the extension in chrome://extensions. Then, in the helper-app folder, run node install-service.mjs --remove. Local data lives next to it (helper folder). Delete it only after the Sync tab shows nothing pending.

Something isn't working

"Helper not running": run setup again, or restart the computer. Offline in the Sync tab: your data is safe on this computer and syncs automatically when the master is back. Capture finds nobody: wait for the results to load, scroll through them once, then capture again.
